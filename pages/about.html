О системе

Web-платформа мониторинга первичной обработки зерна

Назначение проекта

Дипломный проект — разработка web-сайта для мониторинга и управления процессами первичной обработки зерна на базе АО «Балашовская хлебная база». Решение объединяет публичную витрину предприятия, операторский мониторинг, складской учёт и администрирование в едином интерфейсе с API на ASP.NET Core и БД MS SQL Server.

Данные

  • Партии зерна, силосы, культуры
  • Заявки на операции (сушка, хранение, анализ)
  • Пользователи и роли доступа
  • Внутренний мессенджер поддержки

Роли

  • Клиент — заявки, сообщения, контакты
  • Оператор / менеджер — мониторинг, склад, справка о процессах
  • Администратор — регистрации, центр управления, аналитика
